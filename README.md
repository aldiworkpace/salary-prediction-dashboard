# salary-prediction-dashboard

# 📊 Global Tech Job Salary Analytics Dashboard

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://salary-prediction-dashboard-dwmkwmxchymwtymdogvch9.streamlit.app/)

## Tentang Project ini
Proyek ini adalah *dashboard* interaktif berbasis web yang dibangun untuk menganalisis tren gaji berbagai profesi di bidang teknologi dan data (seperti Data Analyst, Data Engineer, dll) di seluruh dunia. Dashboard ini memungkinkan pengguna untuk memfilter data berdasarkan profesi dan langsung melihat visualisasi wawasan bisnis secara *real-time*.

## 🎯 Business Insights
Melalui *dashboard* ini, kita dapat menjawab beberapa pertanyaan kunci seputar industri:
- **Pengaruh Pengalaman & Sertifikasi:** Menganalisis seberapa besar dampak tahun pengalaman dan jumlah sertifikasi terhadap peningkatan gaji.
- **Geospasial:** Memetakan negara mana saja yang menawarkan rata-rata gaji tertinggi.
- **Sistem Kerja (Remote vs WFO):** Menjawab mitos apakah pekerja *Remote/Hybrid* dibayar lebih rendah atau lebih tinggi dibanding pekerja *On-site*.
- **Skala Perusahaan:** Membandingkan penawaran gaji antara perusahaan raksasa (*Enterprise/Large*) melawan perusahaan rintisan (*Startup/Small*).

##  Fitur Utama
* **Interactive Sidebar Filter:** Pemilihan profesi yang dinamis (*dropdown*) yang otomatis memperbarui seluruh data di *dashboard*.
* **Raw Data Viewer:** Tabel sekilas untuk melihat bentuk data asli.
* **Line Chart & Bar Charts:** Visualisasi tren yang jelas dan mudah dipahami.
* **Geospatial Mapping:** Peta dunia interaktif (*Choropleth map*) untuk melihat sebaran gaji secara global.
* **Donut Chart:** Visualisasi proporsi sistem kerja karyawan.
* **Responsive Grid Layout:** Tampilan yang dioptimalkan dengan struktur kolom (bersebelahan) agar rapi dan profesional.

## 🛠️ Teknologi yang Digunakan
* **Python:** Bahasa pemrograman utama.
* **Pandas:** Untuk manipulasi, pembersihan, dan agregasi data (*Data Wrangling*).
* **Streamlit:** Untuk membangun antarmuka web interaktif (*Web Framework*).
* **Plotly Express:** Untuk merender grafik dan peta interaktif yang dinamis.
